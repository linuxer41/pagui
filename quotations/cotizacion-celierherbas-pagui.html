Resumen Técnico

Pagui es una API REST de conexión bancaria directa, respaldada por Banco Económico. Está diseñada para que desarrolladores integren cobros y pagos en sus propios sistemas mediante llamadas HTTP estándar, sin necesidad de implementar la conexión con el banco, el hardware de encriptación ni el cumplimiento de las normas ISO del sistema bancario.

Recursos de la API

POST/auth/loginAutenticación de usuario (email + contraseña)
POST/transfers/p2pTransferencia P2P (idempotente + validación de fraude)
POST/walletsConsulta de saldo y movimientos de billetera
POST/qr/crearGenera código QR de cobro dinámico
POST/merchants/payPago a comercio mediante Pagui
POST/subscriptionsCrea suscripción recurrente (diaria/semanal/mensual/anual)
POST/split/payPago compartido múltiple entre participantes
POST/nfc/preparePrepara pago NFC sin conexión (offline)

Autenticación

Autenticación con JWT (obtenido en POST /auth/login) más API Key vía header X-API-Key: [tu_api_key]. Las credenciales se entregan al momento de la activación.

// Ejemplo: cobrar con QR (JavaScript/Node) const token = await login({ email, password }); const qr = await fetch('https://api.pagui.bo/qr/crear', { method: 'POST', headers: { 'Authorization': `Bearer ${token}`, 'X-API-Key': apiKey }, body: JSON.stringify({ monto: 250.00, concepto: 'Pago de servicio' }) });
// Ejemplo: transferencia P2P (PHP) $response = $client->post('https://api.pagui.bo/transfers/p2p', [ 'headers' => [ 'Authorization' => "Bearer {$token}", 'X-API-Key' => $apiKey, 'Idempotency-Key' => uniqid() ], 'json' => [ 'monto' => 100.00, 'cuentaDestino' => '1234567890' ] ]);

Seguridad y Cumplimiento

  • Cifrado AES-256 para datos sensibles (seed phrases, llaves biométricas)
  • Idempotencia en operaciones (header Idempotency-Key): evita duplicados
  • Validación de fraude (velocidad, monto, hora, dispositivo) previa a cada operación
  • Hardware de encriptación y cumplimiento de normas ISO exigidas por el sistema bancario
  • WebSockets con autenticación JWT para notificaciones en tiempo real

Panel de Control

  • Administración de API Keys (generar, revocar, renovar)
  • Configuración de cuentas bancarias y credenciales del banco
  • Visualización de operaciones, movimientos y comisiones generadas
  • Reportes exportables

Estructura de Costos

La activación es un pago único por el alta del NIT/empresa. La comisión del 0.1% se cobra solo por operaciones procesadas, no se descuenta del dinero en tránsito y se factura al cierre de cada mes.

Condiciones

Activación

Pago único de Bs 600. Incluye alta del emisor, entrega de credenciales (JWT + API Key) y acceso a documentación.

Comisión

0.1% por operación procesada. No se descuenta del dinero en tránsito; se factura al final de cada mes mediante nota de débito.

Integración

El desarrollador implementa usando la documentación y ejemplos provistos. Soporte técnico incluido para dudas sobre la API.

Sin costos fijos

No hay tarifas fijas mensuales ni tarifas ocultas. El banco no cobra ninguna comisión.
