Resumen Técnico

Factugest es una API REST de facturación electrónica autorizada por Impuestos Nacionales. Está diseñada para que sistemas externos puedan emitir, anular y consultar facturas mediante llamadas HTTP estándar, sin necesidad de implementar la lógica de contingencia, validación ni comunicación con el ente tributario.

Recursos de la API

POST/api/v1/factura/emitirEmite una factura electrónica (contingencia automática si SIN está caído)
POST/api/v1/factura/anularAnula una factura existente por CUF
GET/api/v1/factura/:cufConsulta estado y datos de una factura
GET/api/v1/factura/pendientesLista facturas pendientes de validación
POST/api/v1/empresa/configActualiza configuración del emisor
POST/api/v1/firma/subirSube firma digital (archivo .p12)

Autenticación

API Key vía header X-API-Key: [tu_api_key]. Las credenciales se entregan al momento de la activación del NIT.

// Ejemplo: emitir factura (PHP) $client = new \GuzzleHttp\Client(); $response = $client->post('https://api.factugest.bo/v1/factura/emitir', [ 'headers' => ['X-API-Key' => $apiKey], 'json' => [ 'nitEmisor' => '123456789', 'cuf' => '...', 'montoTotal' => 1200.00, 'detalle' => [/* ... */] ] ]);
// Ejemplo: emitir factura (JavaScript/Node) const response = await fetch('https://api.factugest.bo/v1/factura/emitir', { method: 'POST', headers: { 'X-API-Key': ${apiKey} }, body: JSON.stringify({ nitEmisor, cuf, montoTotal, detalle }) });

Panel de Control

Aplicación de escritorio instalable que permite gestionar la configuración del emisor sin usar la API directamente:

  • Registro y edición de datos de empresa por NIT
  • Administración de API Keys (generar, revocar, renovar)
  • Carga de firma digital (.p12)
  • Validación manual de facturas pendientes
  • Facturación fuera de línea (offline) con sincronización automática al recuperar conexión
  • Visualización de contingencias activas e históricas
  • Exportación de reportes

Manejo de Contingencias

Factugest gestiona automáticamente los siguientes escenarios sin intervención del integrador:

  • Corte de luz: La cola de facturas se reanuda al restaurar el servicio
  • Caída de internet: Las facturas se almacenan localmente y se sincronizan al recuperar conexión
  • Caída del SIN (Impuestos Nacionales): Se activa modalidad contingente automática; las facturas se validan cuando el SIN retorna
  • Corte de línea telefónica: Sin efecto — la comunicación es vía internet

Estructura de Costos

En Impuestos Nacionales, cada NIT tiene una sucursal 0 (casa matriz). El costo base cubre el NIT completo incluyendo la sucursal 0. Las sucursales adicionales (1, 2, 3...) tienen un recargo del 30% sobre el base.

ConceptoMensualAnual (×11)
Licencia API por NIT (incluye sucursal 0)Bs 120Bs 1.320
Sucursal adicional — recargo 30% sobre baseBs 36Bs 396
// Cálculo de ejemplo (anual) const nitBase = 120 * 11; // Bs 1.320/año por NIT const sucursalExtra = 36 * 11; // Bs 396/año por sucursal extra function total(nits, sucursalesExtras) { return (nits * nitBase) + (sucursalesExtras * sucursalExtra); } total(1, 0); // => Bs 1.320/año

Condiciones

Licencia

Anual por NIT. Incluye acceso a API, panel de control y actualizaciones normativas.

Sucursales

Cada sucursal adicional tiene un recargo del 30% sobre el costo base del NIT (Bs 36).

Integración

El integrador implementa usando la documentación y ejemplos provistos. Soporte técnico incluido para dudas sobre la API.

Actualizaciones

Cambios normativos de Impuestos Nacionales se actualizan automáticamente sin costo adicional.
