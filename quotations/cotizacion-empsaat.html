Solicitud

Se solicita la modificación del sistema de control interno EMPSAAT para soportar carnets con extensión en la facturación (formato Bolivia, ej. 7474483-1B), que actualmente el sistema no admite.

Alcance

  • Sistema de control interno EMPSAAT: el campo de carnet pasará a aceptar el formato con extensión (ej. 7474483-1B) con su validación.
  • Base de datos SQL Server: se modificará el esquema para almacenar la extensión del carnet sin afectar los datos existentes.
  • Comunicación con la API de facturación (Factugest): se adecuará el envío del carnet con extensión para generar la factura correctamente.
  • Compilación nueva: se generará la versión actualizada del sistema de control interno y del sistema de facturación.
